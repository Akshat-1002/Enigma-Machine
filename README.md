# Enigma-Machine
This repository contains two browser-based mini-projects built using HTML, CSS, and JavaScript:

🔹 Dcoder
A simple web-based code editor that mimics the core interface of platforms like Dcoder. It provides a text area for writing code and a basic UI for a coding environment. Ideal for demonstrating how in-browser editors function at a fundamental level.

🔹 Enigma Simulator
A digital recreation of the historic Enigma encryption machine. Users can type input text and see how it would be encoded by the simulated rotors, replicating the logic behind WWII-era encryption.
